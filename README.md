# coatless-brand-yml.github.io

Auto-built project index for [coatless-brand-yml](https://github.com/coatless-brand-yml), deployed to
[brand-yml.thecoatlessprofessor.com](https://brand-yml.thecoatlessprofessor.com/).

Source: [coatless/quarto-org-index](https://github.com/coatless/quarto-org-index).

Rebuilt daily by GitHub Actions plus on push to `main` and on
`repository_dispatch` event `refresh`.
